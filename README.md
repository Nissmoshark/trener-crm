# Журнал тренувань (Appwrite)

CRM персонального тренера: розклад, клієнти, абонементи, оплати й борги, переноси, статистика, Telegram-бот.

- `app/` — веб-додаток (Appwrite Sites, статичний). Адреса сервера — у `app/config.js`.
- `functions/trainer/` — Appwrite Function (Node 22, без залежностей): API, Telegram-бот, щохвилинні нагадування.
  Під час першого запуску сама створює базу `trainer` і колекції. Працює з динамічним ключем функції.
- `test/` — тести логіки: `node test/run.mjs`.

Безпека: вхід за номером телефону й паролем (PBKDF2), обмеження спроб, скидання пароля через Telegram.
Бот підключається лише після підтвердження номера кнопкою «Надіслати мій номер» — номер має збігатися з номером у журналі.
